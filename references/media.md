# 本地照片和视频整理

## 先确定归属，再执行复制

建议原片留在项目外：`旅行原片/中国/云南/大理/照片或视频/`。城市可以省略。整理时结合已有目录、原始文件名、EXIF 拍摄时间、GPS 与明确行程；GPS 反查地点需要用户允许的数据访问方式。脚本不会自动做人脸识别、画面识别、GPS 反向地理编码，也不会替 AI 决定不明确的省州或城市。

已提供明确文件夹或日期的素材可继续处理。对缺失日期、位置冲突、未知城市等项列出待确认文件；不要用修改时间冒充拍摄时间，也不要根据画面猜一个省州。需要分析画面才能分类时，按可用图像工具处理，不能把非视觉元数据当成已看过图片的证据。

地区 ID 从 `public/data/world.topo.json` 的 `objects.regions.geometries[].properties` 查询：`id`、`name`、`countryId`、`countryName`。使用地图的实际 ID，不仅按 ISO 常识拼接。城市仅是相册标签，不增加地图行政层级。

## 导入计划格式

把已确认的文件整理成计划 JSON。`source` 必须是绝对路径，`date` 为真实 `YYYY-MM-DD`，`credit` 为实际作者；没有城市时整个省略 `city` 字段。`creditUrl`、`licenseUrl` 可选。

```json
{
  "items": [
    {
      "source": "/绝对路径/旅行原片/中国/云南/大理/照片/IMG_001.jpg",
      "regionId": "CN-YN",
      "city": { "id": "dali", "name": "大理" },
      "type": "photo",
      "date": "2025-10-01",
      "title": "洱海日落",
      "credit": "本人拍摄"
    },
    {
      "source": "/绝对路径/旅行原片/中国/云南/视频/IMG_002.mov",
      "regionId": "CN-YN",
      "type": "video",
      "date": "2025-10-02",
      "title": "山间散步",
      "credit": "本人拍摄"
    }
  ]
}
```

计划包含原片绝对路径，应放在项目外或临时目录，不随公有仓库和部署文件发布。输出索引只保存内容哈希用于去重，不保存原片路径。

## 预检与执行

```bash
node "<Skill目录>/scripts/import-media.mjs" --project "<项目目录>" --plan "<计划文件.json>"
node "<Skill目录>/scripts/import-media.mjs" --project "<项目目录>" --plan "<计划文件.json>" --apply
```

生成的项目也内置同一脚本：`npm run import:media -- --project . --plan "<计划文件.json>" [--apply]`。

默认仅预检，不改项目。已有用户导入授权、计划全部确定且在授权范围内时，展示预检结果后继续执行，不重复询问同一项授权。未知地点/日期的确认、覆写现有数据和公开素材是不同问题；后两者不由此导入脚本自动执行。

脚本按内容哈希跳过完全相同的原片；不会删除重复原片，不按类似照片或文件名去重。导入模式只有追加，不替换或删除既有相册。相同源文件需要改城市时，应明确修改既有索引，不能用重复导入假装已经移动分类。

新展示文件按稳定 ID 输出：

```text
public/media/albums/CHN/CN-YN/dali/photos/import-内容摘要.jpg
public/media/albums/CHN/CN-YN/_region/videos/import-内容摘要.mp4
public/media/thumbs/CN-YN/dali/import-内容摘要.jpg
```

无城市时使用内部目录 `_region`，索引中不添加虚构的城市标签。目录用稳定代码，界面展示地图与计划中真实的中文名称。

图片使用 JPEG，保持比例且不放大小图，长边上限 2400；缩略图长边上限 480。该输出面向摄影素材，透明图片转 JPEG 不保留透明通道；需要透明度的素材应另行保留 PNG。视频保持全长，保留第一条音轨，转为 H.264/yuv420p + AAC/faststart MP4，画面长边上限 1920 并按编码要求取偶数尺寸。根据实际输出读取尺寸与时长，不复制原片中可能已经旋转的宽高。展示副本清除原始元数据，拍摄日期留在相册索引；原片不修改。

JPEG/PNG/WebP/TIFF/BMP/AVIF 等图片的实际支持取决于本机 FFmpeg。HEIC/HEIF 若当前 FFmpeg 无法解码，应报告失败，让用户导出 JPEG 或使用已安装的可靠工具转换；RAW 不在内置扩展名支持范围，不能假装已成功导入。Live Photo 的静态照片与短视频分别登记。HDR/广色域素材当前没有专用色彩管理，应告知用户需要另行校色/转换，而不是声称输出等同原片。

整批先预检，再在临时目录转换；任一转换失败时，不提交本批索引。复制时拒绝覆盖和符号链接路径，失败回收本次输出，原片仍保留。失败项先报告，修正计划后只重试需要的项，不盲目把失败算成成功。

## 完成验证

运行 `npm run typecheck`、`npm run check:data`、`npm run build`。确认地区、城市及类型数与计划一致；文件和封面存在；视频时长、音频和旋转正常；重复执行同计划不新增条目。新地区首页入口和数量必须从真实索引计算，不硬编码云南或要求至少一张照片。

对于现有原版项目，检查脚本最后的“四种示例场景覆盖”断言只适用于演示数据。用户全部换成真实素材后可移除该段；必须保留关联、文件存在、真实尺寸、视频编码/时长以及地图几何检查。不要把准备示例的 `prepare:media` 用在个人原片上。
